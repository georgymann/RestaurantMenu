# RestaurantMenu

Десктопное приложение для просмотра и редактирования меню заведений: ресторанов, кафе и кофеен.
В приложении можно выбрать заведение, открыть его обычное или сезонное меню, найти нужные блюда,
отфильтровать позиции по категории и наличию, а также добавить, изменить или удалить блюда.
После редактирования меню можно сохранить в файл.

## Запуск

**Через Visual Studio:**
1. Открыть файл решения `RestaurantMenu.sln`.
2. В обозревателе решений (Solution Explorer) щёлкнуть правой кнопкой по проекту RestaurantMenu →
   Set as Startup Project (назначить запускаемым).
3. Нажать **Ctrl+F5** — приложение запустится.

**Через терминал:**
```
dotnet run --project RestaurantMenu
```

## Главное окно

Слева — панель выбора, справа — карточка выбранного заведения.

| Элемент | Назначение |
|---|---|
| **«Тип заведения»** | Фильтр списка: Все · Рестораны · Кафе · Кофейни. |
| **«Заведение»** | Выбор заведения — справа появляется карточка. |
| **«Вид меню»** | Обычное / Сезонное. Активен после выбора заведения; «Сезонное» — только если есть. |
| **«Формат файлов»** | JSON или XML. По умолчанию JSON. |
| **«Показать меню»** | Открывает окно меню. Неактивна, пока не выбрано заведение. |

В карточке справа: название, тип, статус, рейтинг, описание, детали (адрес, телефон, сайт-ссылка).

## Окно меню

Слева — боковая панель, справа — таблица блюд.
Колонки: Название · Категория · Цена · Описание · Параметры · Доступно.

| Элемент | Назначение |
|---|---|
| **«Меню»** | Переключение Основное / Сезонное. |
| **«Блюда» / «О заведении»** | Таблица блюд / окно с информацией о заведении. |
| **Поиск** | Фильтр по названию. |
| **«Категория» / «Наличие»** | Фильтры по категории и доступности. |
| **«+ Добавить блюдо»** | Открывает окно добавления. |
| **«⋮» в строке** | Меню «Редактировать» / «Удалить». |
| **«Удалить позицию»** | Удаляет выделенное блюдо. |
| **«Сохранить меню»** | Записывает меню в файл в выбранном формате. |

Изменения (добавление, редактирование, удаление) хранятся в памяти и попадают в файл только после
кнопки **«Сохранить меню»**.

## Окно «Добавить блюдо»

Модальное окно.

| Элемент | Назначение |
|---|---|
| **«Тип блюда»** | Список зависит от заведения. |
| Название / Цена / Описание | Основные поля. |
| Числовые поля и флажки | Меняются под выбранный тип блюда. |
| **«Добавить» / «Отмена»** | Создать блюдо / закрыть без сохранения. |

При ошибке ввода (пустое название, отрицательная цена и т. п.) показывается красный текст, окно не закрывается.

## Окно «Редактировать блюдо»

Модальное окно. Только для чтения: название, категория, параметры. Можно менять: описание, цену,
доступность. **«Сохранить»** — применить (с проверкой), **«Отмена»** — закрыть.

## Окно «О заведении»

Показывает название, тип, статус, рейтинг, описание и характеристики заведения. Сайт — кликабельная ссылка.

## Хранение данных

- Файлы заведений лежат в `RestaurantMenu/DataFiles/Json` (`*.json`) и при сохранении в XML —
  в `RestaurantMenu/DataFiles/Xml` (`*.xml`).
- Имя файла формируется как `Тип_Название` (например, `CoffeeShop_Bodro Coffee.json`).
- При запуске заведения читаются из JSON. Сохранение и смена формата записывают данные в выбранном
  формате.

## Технологии

- C# / .NET 8
- Avalonia UI (+ тема Semi.Avalonia)
- Newtonsoft.Json — сериализация JSON
- System.Xml.Serialization — сериализация XML
